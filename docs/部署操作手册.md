# ifami 部署操作手册（本机原生，无 Docker）

> 目标：从代码到用户可用的线上小程序。覆盖三块工作：**域名+备案 → ECS 后端 → 微信小程序**。
> 前置阅读：[docs/前置事项.md](前置事项.md)（主体决策、备案材料、微信注册、订阅消息模板）。
> 链路：小程序 → HTTPS → Caddy（`api.ifami.site:443`）→ 本机 `127.0.0.1:8080`；服务号 H5 → Caddy `/h5/*` 静态。
> 部署形态：**完全本机原生**——MySQL / Redis / Caddy / ifami（api+worker）都装在同一台 ECS 上，api/worker 用 systemd 守护，**不装 Docker**。

## 0. 总览与关键路径

**关键路径 = ICP 备案**（个人主体约 1–3 周），因为它卡着「小程序合法域名」的配置：微信要求 request 合法域名必须 **已备案 + HTTPS**。所以备案最先启动，其余并行推进。

| 阶段 | 动作 | 是否依赖备案 |
|---|---|---|
| A | 域名解析（DNS） | 否，立刻做 |
| B | ICP 备案 | —（关键路径） |
| C | ECS 装 MySQL/Redis/Caddy/Go + 跑通后端 | 否，备案等待期即可做完 |
| D | HTTPS 证书（Caddy 自动） | 是（根域名未备案时内地主机可能被拦截） |
| E | 小程序配置合法域名 + 发布 | 是 |

> 本手册当前写的是「MySQL 本机安装」；后续切火山 RDS 见 §6，只改 `RDS_DSN`。

## 1. 域名解析（无审核，立刻做）

火山引擎 DNS 控制台，加 A 记录：

| 记录 | 值 |
|---|---|
| `api.ifami.site` | ECS 公网 IP |
| `ifami.site` | ECS 公网 IP（H5 落地页，可选） |

## 2. ICP 备案（最先启动，1–3 周）

流程与材料见 [前置事项.md §1](前置事项.md)。要点：

1. 先买好 ECS（备案要求接入商处有云资源）。
2. 火山引擎备案系统提交，主体选**个人**，网站性质填**非经营性个人网站**。
3. 备案通过后：ECS 安全组放通 `80`、`443`（保留 `22` SSH）；**`3306` 不放**（MySQL 只本机用）。

## 3. ECS 后端部署（备案等待期即可做）

> 分工：§3.1–3.4 中间件（MySQL/Redis/Caddy/Go）**手动安装**；装完后 `cd /opt/ifami && sudo bash deploy/bootstrap.sh` 只做检测，通过后自动完成密钥生成、建库建表、编译、systemd 启动与健康检查（幂等，可重复跑）。

### 3.1 装 MySQL（本机）

火山 ECS 多为 Ubuntu / veLinux，按系统选：

```bash
# Ubuntu / Debian
sudo apt update && sudo apt install -y mysql-server
sudo systemctl enable --now mysql

# veLinux / CentOS / Rocky
sudo dnf install -y mysql-server   # 或 mariadb-server
sudo systemctl enable --now mysqld
```

配置 utf8mb4 + **只监听本机回环**（api/worker 经 `127.0.0.1` 访问，不对外）：

```bash
sudo tee -a /etc/mysql/mysql.conf.d/mysqld.cnf <<'EOF'
[mysqld]
character-set-server = utf8mb4
collation-server = utf8mb4_unicode_ci
bind-address = 127.0.0.1
EOF
sudo systemctl restart mysql
```

建库 + 应用账号（`<应用密码>` 与后面 `.env` 的 `RDS_DSN` 密码一致）：

```bash
sudo mysql <<'SQL'
CREATE DATABASE IF NOT EXISTS ifami CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER IF NOT EXISTS 'ifami'@'localhost' IDENTIFIED WITH mysql_native_password BY '<应用密码>';
GRANT ALL PRIVILEGES ON ifami.* TO 'ifami'@'localhost';
FLUSH PRIVILEGES;
SQL
```

### 3.2 装 Redis（本机）

```bash
# Ubuntu / Debian
sudo apt install -y redis-server
sudo systemctl enable --now redis-server

# veLinux / CentOS / Rocky
sudo dnf install -y redis
sudo systemctl enable --now redis
```

默认只监听 `127.0.0.1:6379`，纯缓存可丢，无需持久化配置。

### 3.3 装 Caddy（本机，静态二进制，自动 HTTPS）

```bash
# 下载静态二进制（全发行版通用）
curl -fsSL "https://github.com/caddyserver/caddy/releases/download/v2.9.1/caddy_2.9.1_linux_amd64.tar.gz" -o /tmp/caddy.tgz
sudo tar -C /usr/local/bin -xzf /tmp/caddy.tgz caddy

# 建 caddy 运行用户 + 数据目录，装 systemd 单元
sudo useradd --system --home-dir /var/lib/caddy --create-home --shell /usr/sbin/nologin caddy
sudo mkdir -p /etc/caddy
sudo chown -R caddy:caddy /var/lib/caddy
sudo cp /opt/ifami/deploy/caddy.service /etc/systemd/system/
sudo systemctl daemon-reload && sudo systemctl enable --now caddy
```

> 后续装载配置：`sudo cp deploy/Caddyfile /etc/caddy/Caddyfile && sudo systemctl reload caddy`（§3.8 会做）。

### 3.4 装 Go 工具链（go.mod 要求 ≥1.23）

```bash
# 与本机开发版本对齐（1.25.7）；大陆 ECS 用阿里云镜像，go.dev 常被墙
wget https://mirrors.aliyun.com/golang/go1.25.7.linux-amd64.tar.gz
sudo tar -C /usr/local -xzf go1.25.7.linux-amd64.tar.gz
echo 'export PATH=$PATH:/usr/local/go/bin' | sudo tee /etc/profile.d/go.sh
source /etc/profile.d/go.sh
go version
```

### 3.5 拉代码

```bash
mkdir -p /opt/ifami
git clone <你的仓库地址> /opt/ifami
cd /opt/ifami
```

### 3.6 小程序 API 地址（已内置，无需手改）

`miniapp/app.js` 的 `apiBase` 默认已指向 Phase 0 服务器：

```js
apiBase: 'http://118.196.79.193',
```

> 备案完成前为 IP 直连 HTTP，开发者工具需勾选「不校验合法域名」；本地联调可临时改回 `http://127.0.0.1:8080`。
> **备案完成、Caddy 切换 HTTPS 后，务必改为 `https://api.ifami.site`**——正式版小程序强制 HTTPS + 合法域名。

### 3.7 配置 `.env`

```bash
cd /opt/ifami/deploy
cp .env.example .env
chmod 600 .env
```

先本地生成两个密钥，**把输出原样（字面字符串）填进 `.env`**——systemd 读取 `.env` 不做 shell 展开：

```bash
openssl rand -base64 32   # 输出填 FIELD_ENC_KEY
openssl rand -hex 32      # 输出填 INVITE_SECRET
```

`.env` 必填/改写项（`< >` 换成实际值）：

```bash
# MySQL（本机 127.0.0.1:3306）
MYSQL_ROOT_PASSWORD=<宿主机root密码>
RDS_DSN=ifami:<应用密码>@tcp(127.0.0.1:3306)/ifami?parseTime=true  # 与 §3.1 建库密码一致

# Redis（本机）——保持默认即可
REDIS_ADDR=127.0.0.1:6379

# 密钥（用上面 openssl 的输出原样粘贴）
FIELD_ENC_KEY=<base64输出>
INVITE_SECRET=<hex输出>

# 微信
WX_MINIAPP_APPID=wxcf35b1844a8c3fe0
WX_MINIAPP_SECRET=<小程序后台 AppSecret>

# 个人主体无服务号，留空即可
WX_OFFIACCOUNT_APPID=
WX_OFFIACCOUNT_SECRET=
```

> 密码/密钥别带 `$`、空格、`#`、反引号等特殊字符，避免 `.env` 被 source 时解析错乱。`MIGRATIONS_DIR=/opt/ifami/migrations` 保持默认不用改。

### 3.8 编译 + 迁移 + 装 systemd 服务

```bash
cd /opt/ifami
CGO_ENABLED=0 go build -o ifami ./cmd/ifami          # 编译单二进制（api/worker 共用）

# 建表（幂等，可重复跑；内部读 .env 里的 RDS_DSN + MIGRATIONS_DIR）
set -a; . deploy/.env; set +a; ./ifami migrate

# 安装 systemd 单元并自启
sudo cp deploy/ifami-api.service deploy/ifami-worker.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now ifami-api ifami-worker

# 装 Caddy 配置并加载
sudo cp deploy/Caddyfile /etc/caddy/Caddyfile
sudo systemctl reload caddy
```

### 3.9 验证

```bash
curl -fsS http://127.0.0.1:8080/healthz          # 应返回 {"status":"ok"}
systemctl status ifami-api ifami-worker          # 均为 active (running)
systemctl status redis-server caddy mysql        # 依赖均 active
```

> 后续发布统一在 ECS 本机执行 `deploy/deploy.sh`：`cd /opt/ifami && bash deploy/deploy.sh`（git pull → 编译 → migrate → 重启 systemd → 本机健康检查）。
> 日常启停与看日志用 `deploy/service.sh`：`bash deploy/service.sh start|stop|restart|status|logs [api|worker]`。

## 4. HTTPS 证书（备案通过后自动）

备案通过 + 域名解析正确 + 80/443 放通后，Caddy 会自动向 Let's Encrypt 申请证书。

```bash
curl -fsS https://api.ifami.site/healthz    # 返回 {"status":"ok"} 即证书已生效
```

## 5. 微信小程序发布

### 5.1 配置服务器域名

`mp.weixin.qq.com` → 开发 → 开发设置 → **服务器域名**：

| 类型 | 域名 |
|---|---|
| request 合法域名 | `https://api.ifami.site` |
| uploadFile 合法域名 | `https://api.ifami.site`（后续接 TOS 时改为 TOS 域名） |
| downloadFile 合法域名 | `https://api.ifami.site` |

保存需管理员扫码。**前提：备案通过 + HTTPS 生效**（§4 验证过）。

### 5.2 订阅消息模板

个人主体触达靠「一次性订阅消息」。申请「日程提醒 / 接送提醒 / 打卡提醒」等模板，拿到模板 ID 配给 notify 模块。

### 5.3 上传 → 审核 → 发布

1. 开发者工具打开 `miniapp/`，确认 `project.config.json` appid = `wxcf35b1844a8c3fe0`、`app.js` 的 `apiBase` 已是生产域名。
2. 上传 → 填版本号 + 备注 → 后台「版本管理」设**体验版**（最多 100 人）。
3. 真机全流程自测：登录 → 建家庭 → 加孩子 → 排日程 → 打卡 → 收提醒。
4. 提交审核（工具类目；打卡照片 UGC 需接 `mediaCheckAsync`）→ 通过后发布。

## 6. 后续（可选）切换到火山 RDS

1. 火山建好 RDS MySQL + 库 `ifami` + 账号，改 `.env` 的 `RDS_DSN` 为 RDS 内网地址，重启服务：
   ```bash
   sudo systemctl restart ifami-api ifami-worker
   ```
2. 迁移建表（幂等）：`cd /opt/ifami && set -a; . deploy/.env; set +a; ./ifami migrate`
3. 数据迁移：本机 `mysqldump` 导出 → 导入 RDS。
4. 本机 MySQL 服务可停用（`systemctl disable --now mysql`）。

## 7. 日常运维

```bash
# 备份（建议 cron：0 3 * * * /opt/ifami/deploy/backup.sh）
cd /opt/ifami/deploy && ./backup.sh

# 日志（api / worker 各一份）
journalctl -u ifami-api -f
journalctl -u ifami-worker -f

# 查看服务
systemctl status ifami-api ifami-worker

# 回滚：git 打 tag 后按 tag 重新部署
git tag v0.0.1 && git push --tags
# 回滚部署：在 ECS 上 git checkout <上个tag> 后重跑 compile+migrate+restart
```
