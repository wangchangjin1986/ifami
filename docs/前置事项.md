# 前置事项清单（备案与资源申请）

> 目的：把 Phase 0 开发前所有**有外部审核周期**的事项一次性办完。
> 状态列自行维护：⬜ 未开始 / 🔄 进行中 / ✅ 完成。

## 0. 主体决策：纯个人（Phase 0），后期升个体工商户

Phase 0 以**个人开发者主体**落地：省去全部微信认证费与服务号/开放平台前置，先把日历 + 打卡核心闭环跑起来验证留存；触达能力降级作为验证项接受。

个人主体能力边界与替代：

| 能力 | 个人主体 | Phase 0 替代 |
|---|---|---|
| 服务号模板消息 | ❌ | 小程序一次性订阅消息 |
| `getPhoneNumber` 一键取号 | ❌ | 微信授权 + 手动填手机号（可选） |
| 微信开放平台 unionid | ❌ | openid（单端够用，identities 预留 unionid） |
| 短信签名报备 | ❌ | 暂缓，升个体户后启用 |
| 小程序微信认证 | ❌ | 不认证（¥0），类目选工具类 |
| ICP 备案 | ✅ | 个人备案（非经营性网站） |
| 微信支付 | ✅ 不需要 | V1 无付费 |

**恢复时机（升个体工商户）**：注册个体户后一次性解锁以上 ❌ 项，触达升级回服务号模板消息 + 短信，注册换回 `getPhoneNumber`。改造点见 ADR-002「纯个人主体的降级与恢复点」。

## 1. 域名注册 + ICP 备案 ⬜（关键路径，最先启动）

| 项 | 内容 |
|---|---|
| 在哪办 | 火山引擎购买域名（如 `ifami.site`）→ 火山引擎备案系统提交 ICP 备案 |
| 前置依赖 | 个人身份证；一台火山引擎内地 ECS（备案要求接入商处有云资源） |
| 材料 | 个人身份证、手机号/邮箱、人脸识别核验、网站名称 |
| 周期 | 初审 1–2 天 + 管局审核约 1–3 周（各地不同） |
| 产出 | 备案号 + 可配置的小程序合法域名 |
| 注意 | 备案期间域名不能指向未备案服务；先买 ECS 再提交备案；网站性质填「非经营性个人网站」 |

## 2. 微信小程序注册（个人主体）⬜（与备案并行）

| 项 | 内容 |
|---|---|
| 在哪办 | mp.weixin.qq.com → 注册小程序 → 选择**个人**主体 |
| 前置依赖 | 个人身份证、手机号、全新邮箱 |
| 周期 | 即时（个人主体无需微信认证，¥0） |
| 配置项 | ① 服务类目：**工具 → 效率/生活服务**（个人可过审；不选教育类目）② 用户隐私协议：声明**手机号、相册、摄像头**用途 ③ 服务器域名（备案后填）：request/uploadFile/downloadFile = `https://api.ifami.site` ④ **订阅消息模板**：申请「日程提醒 / 接送提醒 / 打卡提醒」等一次性订阅模板（个人可用） |
| 产出 | AppID/AppSecret；体验版（100 体验成员，Phase 0–1 够用） |
| 注意 | 个人主体无法微信认证，故无 `getPhoneNumber`；打卡照片属 UGC，接 `mediaCheckAsync` 内容安全检测是过审前提 |

## 3. 火山引擎资源开通 ⬜（无审核周期，开发前 1 天办即可）

- 账号**个人实名**认证
- ECS（2C4G）+ 弹性公网 IP（备案也需先有 ECS，与 §1 一起买）
- MySQL：Phase 0 在 ECS 本机安装（定期备份），后续切火山 RDS（基础版，自动备份）
- TOS bucket ×2：`ifami-media`（打卡照片，版本控制）、`ifami-h5`（静态页，可选）
- 火山方舟：开通 + 接入豆包多模态模型（课表识别用）

## 5. 关键路径与时间线

```
第 1 周   域名+ECS 购买 → 提交 ICP 备案 ──────────────┐
         小程序注册（个人主体）＋订阅消息模板申请        │
第 2–3 周 （等待期）开发不停：本地环境 + 体验版          │
第 3–4 周 备案通过 → 配置合法域名 → 全链路联调           │
```

备案等待期不阻塞开发：小程序体验版 + 本地后端（内网穿透或开发者工具关闭域名校验）即可全流程开发联调。
