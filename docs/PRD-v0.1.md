# ifami PRD 草稿 v0.1 —— 以家庭为单位的协作工具

> 状态：讨论稿。方向已定：**先以家庭协作工具切入，后续扩展到家庭圈社交**。
> 目标人群：中国有娃家庭，首发聚焦 4–10 岁（幼儿园中班–小学四年级）的"鸡娃"家庭。
>
> **主体降级说明（2026-10）**：§4–§6 中的「服务号模板消息 / `getPhoneNumber` / unionid / 短信兜底」为**目标态**（升个体工商户后启用）。Phase 0 以纯个人主体落地：触达用小程序一次性订阅消息、无短信，注册用微信授权 + 手机号可选，身份用 openid。降级与恢复点见 [ADR-002](../wiki/architecture/adr-002-notification-receipt.md) 与 [前置事项.md](前置事项.md) §0。

## 1. 定位

一句话：**以"家庭"为账户单位的学习与生活协作空间**。

- 不是个人工具加分享功能，而是账号体系原生围绕家庭组织（父母/老人/孩子/其他照护者）。
- 不做广场、不做排名、默认私密——"反焦虑"是设计原则，也是合规避险。
- 对标空白：海外有 FamilyWall/Cozi（家庭协作订阅制已验证），国内该角色被微信家庭群将就填着，痛点明确（画质压缩、信息刷走、无法结构化、长辈门槛高）。

## 2. 为什么工具先行

| 维度 | 协作工具 | 家庭圈社交 |
|---|---|---|
| 留存 | 强（高频刚需：排课、接送、打卡） | 依赖圈子密度，冷启动难 |
| 传播 | 弱 | 强 |
| 结论 | **做留存基本盘** | 留作 V3 增长引擎 |

工具传播弱的风险，通过内建病毒钩子弥补（见 §5）。

## 3. MVP 功能范围（V1，家庭作战室）

### 3.1 家庭账户与角色
- 家庭为顶级实体；成员角色：爸爸/妈妈/祖辈/孩子/其他（家教、阿姨）。
- 角色权限：父母全功能；**老人极简模式**（只看"今天：几点接娃、去哪、带什么"）；孩子只读+打卡提交。
- 邀请家人即拉新——首个病毒钩子。

### 3.2 家庭日历（核心高频场景）
- 课程表（课外班、学校课表）+ 接送分工 + 冲突检测。
- 周视图 = 每 2 小时时段 × 周一到周日的时间网格，按孩子筛选，格子显示「孩子 · 责任人」。
- 日程绑定责任人："周三 17:00 奶奶接，送到钢琴课"。
- 支持多孩。

### 3.3 打卡
- 家长布置任务（阅读/跳绳/练琴…），孩子打卡（拍照/计时提交）。
- 激励体系**整体后置**：不同家庭激励手段差异大（积分/实物/特权时长），孩子对激励敏感度不同，产品不替家庭做选择。V1 仅预留打卡事件流与成长值字段等扩展钩子；未来按**千人千面激励**建设——家庭可配置方案，同家庭不同孩子可不同方案。
- **进步只和自己比**：个人曲线，无任何排名。

### 3.4 成长档案（付费点雏形）
- 打卡/照片/证书自动沉淀为时间线；月度/年度成长报告。
- 对标亲宝宝 VIP 相册，但更结构化，面向学龄段。

## 4. 账号体系设计

原则：**账号是"人"，家庭是"组织"，成员关系是"边"**。不做家庭共用账号。

- `用户(User) ──< 成员关系(角色+称谓) >── 家庭(Family)`；一人可属多个家庭（祖辈挂多个子女家庭、离异父母共挂孩子、家教服务多家——均为常态而非边缘 case）。
- 三类成员三条注册路径：
  - 父母：微信授权（unionid 打通小程序/服务号/App）+ 手机号兜底。
  - 祖辈：点邀请卡片 → 小程序一键授权 → `getPhoneNumber` 一键取号（免输入，约 ¥0.03/次，需小程序企业认证）→ 选称谓 → 关注服务号。全程 <30 秒，无密码，可不装 App。手机号必选：短信兜底通道的前提，也是 V2 App 账号合并主键。
  - 孩子：**虚拟成员（影子档案）**，父母创建，不登录；打卡在父母设备切换身份提交或代打。`members.user_id` 可空，孩子长大有自己的微信后一键认领，档案无缝转正。孩子手机号**可选**：用于紧急联系卡、（探索）接娃提醒直达电话手表、认领时辅助验证。
- 数据模型：`users(user_id, unionid, phone…)` / `identities(user_id, channel, appid, openid)`（推送通道身份单独成表，配合 §6 触达路由）/ `families` / `members(family_id, user_id NULL, type[real|virtual], role, relation_label, phone NULL（孩子可选）, status)`。手机号加密存储，家庭内默认脱敏展示。
- 权限（V1）：管理员=成员管理+日程/任务录入编辑；父母=日程/任务/档案查看+邀请；祖辈=今日视图+接收提醒+协助打卡+变更反馈（无编辑权，以反馈回路替代）；孩子=仅打卡提交（代管）。家教/阿姨等外部成员 V2 再做。
- 合规：孩子无独立登录、无陌生人触达、监护代管，天然满足未成年人保护要求；V1 不涉支付/UGC，不需要实名。
- 演进：V1 unionid 即账号 → V2 App 用手机号主键 + unionid 绑定，需处理小程序老用户与 App 新注册的合并流程。

## 5. 路线图

- **V1（MVP）**：家庭账户 + 日历分工 + 打卡。**目标态 = 小程序做交互 + 认证服务号做触达中枢**（订阅消息对教育类仅一次性授权，不能依赖；服务号模板消息关注一次即可长期触达）。**Phase 0 纯个人主体例外：无服务号，触达改用订阅消息，见文首降级说明**。需求明细见 [V1-需求列表.md](V1-需求列表.md)。
- **V2**：打卡分享卡片、家庭周报（社交货币，为圈子预热）；千人千面激励（家庭可配置方案，基于 V1 预留的事件钩子）；成长档案订阅（验证付费，节奏另议）。
- **V3 家庭圈**：3–10 个家庭的邀请制结盟群——圈内资料库、打卡互见、拼课拼团。这是增长引擎，必须在工具留存验证后再做。
- **V4（可选）**：机构真实点评/升学政策结构化（需求最刚但运营重、合规风险高，谨慎评估）。

## 6. 触达架构（协作工具的命脉）

触达分三级，通道各不同——**触达能力是本产品区别于"又一个打卡小程序"的核心工程投入**（下表为目标态；Phase 0 纯个人主体无服务号/短信，见文首降级说明）：

| 层级 | 场景 | 通道 |
|---|---|---|
| 强（错过即事故） | 接娃提醒、课程变更 | 祖辈：服务号模板消息 + 短信兜底；父母：App push（V2 起） |
| 中（当天看到即可） | 打卡提醒、提交反馈、周报 | 服务号模板消息为主，小程序订阅消息为辅 |
| 弱（主动查看） | 日历、档案、资料 | 小程序/App 内，不推 |

原则：
- 祖辈**永远不强求装 App**——服务号 + 短信就是他们的客户端，同时是"邀请祖辈零门槛"的拉新钩子。
- 关键提醒短信兜底（参考晓黑板"通知必达"：App+短信+电话三路）。一个家庭每天几条，成本可控。
- 父母是强触达刚需方，App 推出的第一诉求就是接管父母侧 push，而非功能差异。

## 7. 0→1 推广与验证

**Phase 0：自己家 dogfood（创始人即用户 0）**
- 目标：核心闭环在真实日常里跑通——录入、分工、触达到祖辈、打卡坚持。
- 不设指标，快速迭代；观察点：每周是否还在主动录入（还是沦为首周新鲜）？祖辈是否真的看今日视图而不打电话？打卡是否靠它而不是靠吼？
- 范围纪律：此阶段只建"自己家需要的"，用不上的（主理人模式、多家庭切换等）继续后置。
- ⚠️ 陷阱：创始人容忍度无限，"自己能用" ≠ "产品成立"。一切结论以 Phase 1 为准。

**Phase 1：朋友家庭 5–10 家（第一次真实验证）**
- 核心原则：**忍住不帮**。观察他们在无创始人辅导下能否自助完成全部流程——入驻、邀请家人、录入、日常使用。
- 过关条件（达不到则回炉，不进 Phase 2）：
  1. 无帮助完成家庭组建+成员入驻 ≥80%
  2. 4 周留存（仍每周有协作行为）≥50%
  3. 祖辈真实使用（打开今日视图/对提醒有响应）≥50%
  4. 待验证假设在此阶段集中验掉：纯记录打卡 30 天留存、拍照识别对激活率的拉动、服务号触达真实到达率、祖辈变更反馈使用率、周视图"责任人 vs 课名"偏好
- 注意：朋友会嘴下留情，定性反馈要打折听，以行为数据为准。

**Phase 2：半公开 50–200 家**
- 渠道：家长 KOC、小区/班级群渗透，从"微信群打卡工具化"切入。
- 此时才开始看北极星：家庭周活跃协作次数；次级：单家庭平均成员数。
- 病毒钩子：邀请家人（祖辈）天然拉新；打卡分享卡片、家庭周报转发（V2 社交货币）。

**迁移路径**：小程序验证协作闭环 → App 承接父母侧重协作与 push → V3 家庭圈放大增长。

## 8. 合规红线

- 不做学科培训营销、不做排名及排名收费（班级优化大师前车之鉴；教育部等八部门 2019 教育 APP 监管意见）。
- 未成年人内容按最严标准：默认私密、无公开信息流、无陌生人触达。
- to-school（家校沟通）不碰，纯家庭侧场景。

## 9. 竞品参照（调研摘要 2026-10）

- 记录型：亲宝宝（极简记录+私密相册，社交弱，学龄后流失）、小福家（私密家庭空间+多端）。
- 社区型：妈妈网（MAU 约 2460 万，开放社区=焦虑放大器）。
- 家校：晓黑板 2022 停服；班级优化大师取消排名后收缩。
- 海外协作：FamilyWall（$44.99/年）、Cozi（$39/年）、Life360（定位向）。
- 鸡娃工具：趣学星球（家长布置+孩子打卡+游戏化，小学阶段）。
- 空位：**学龄段 × 家庭级协作 × 私密小圈子**无人承接。
