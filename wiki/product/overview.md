# 产品概览

## 一句话定位

以"家庭"为账户单位的学习与生活协作空间。**家庭是组织，不是个人工具的分享附属品。**

## 目标用户

中国 4–10 岁孩子（幼儿园中班–小学四年级）的家庭，首发"鸡娃"家庭。特征：多角色协作（爸妈分工、祖辈接送、机构外包）、强打卡习惯、信息焦虑。

## 解决的核心问题（JTBD）

1. 排课与接送分工靠微信群吼，经常撞车 → **家庭日历 + 责任人分工**
2. 打卡坚持不下来，过程无记录无反馈 → **打卡任务 + 进步曲线（只和自己比）**
3. 祖辈不知道"今天该干嘛" → **聚合今日视图 + 大字模式**
4. 关键提醒在微信群里被刷走 → **三级触达 + 确认回执 + 升级兜底**
5. 成长数据散落各处 → **成长时间线 + 家庭周报**

## V1 范围

家庭与成员 / 日历分工（周视图 P0、月视图 P1）/ 打卡（激励后置）/ 触达中枢 / 成长时间线与周报（P1）/ 上下文评论（P1）。
